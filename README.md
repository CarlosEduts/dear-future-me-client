# Dear Future Me — Web Client

> Interface do **Dear Future Me**. Este projeto foi construído para oferecer uma experiência fluida, focada na facilidade de escrita para o seu "eu do futuro".

## Stack Tecnológica

- **Framework:** Next.js 14+ (App Router)
- **Linguagem:** TypeScript
- **Estilização:** Tailwind CSS & Shadcn/ui
- **Ícones:** Lucide React

## Padrões de Código

- **Componentização:** Priorização de componentes funcionais e puros.
- **CSS-in-JS:** Uso estrito de Tailwind para manter o bundle leve e consistente.
- **Tipagem:** 100% de cobertura com TypeScript para evitar runtime errors.
